# Real-Time Face and Eye Detection using OpenCV

This project implements a computer vision system to detect faces and eyes in real-time using Python and OpenCV.

## 🔧 Technologies Used
- Python
- OpenCV
- Haar Cascade Classifiers
- Google Colab

## 📁 Project Structure
```
face-eye-detection/
├── face_eye_detection.py
├── haarcascade_frontalface_default.xml
├── haarcascade_eye.xml
└── README.md
```

## 🚀 How to Run
1. Install OpenCV:
   ```bash
   pip install opencv-python
   ```
2. Run the detection script:
   ```bash
   python face_eye_detection.py
   ```

## 🎯 Features
- Real-time face and eye detection
- Uses OpenCV's pre-trained Haar Cascade models
- Highlights detected faces and eyes with bounding boxes

## 📝 Notes
- Designed for webcam input but can be modified to process image files.
- Ideal for learning about basic object detection in OpenCV.
